Native aarch64 and x86_64 packages for Omarchy on Arch Linux. Install or update with the README one-liner:

```bash
curl -fsSL https://raw.githubusercontent.com/avillagran/omarchy-t3-code/main/install.sh | bash
```

## Highlights

### Thread mosaic

Watch 1 to 8 threads live side by side. Each tile shows its phase with its own color and motion: T3's working blue while an agent thinks, reads, edits, runs or answers; a distinct tone when it waits for you, fails or finishes. Tiles keep their slots, page with a flip, can be filtered, and follow streamed text like the chat until you scroll up.

### Quick replies

A quick replies button in the composer sends your saved answers in one click. The list is configurable in Preferences.

### Host filter and fuzzy sidebar search

- **Host filter**: show only the threads of one machine.
- **Fuzzy search** ignores accents, case and word order, tolerates typos, matches host names and finds messages on the server. The sidebar stays put when nothing matches.
- Sidebar lists scroll by wheel or touchpad only, so a click is never swallowed by a drag.

### Dictation keeps long recordings whole

- Dictations longer than 25 seconds are split at natural pauses and transcribed piece by piece, so a several-minute dictation comes back complete instead of truncated.
- Each recording and its text are kept per thread. Rest the mouse on the microphone to play, delete or open them. **Preferences → Dictation → Keep recordings** sets how long they stay; they go when the thread is archived or deleted.

## Fixes

- Git failures such as "Author identity unknown" or "Authentication failed" now show git's reason instead of a missing-permission message; a real missing permission names the scope it needs.
- Client activity reports reach the server again, and importing sessions without a project no longer fails.
- All T3 traffic now goes through the shared T3 protocol library.
