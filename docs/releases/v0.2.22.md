Native aarch64 and x86_64 packages for Omarchy on Arch Linux. Install or update with the README one-liner:

```bash
curl -fsSL https://raw.githubusercontent.com/avillagran/omarchy-t3-code/main/install.sh | bash
```

## Highlights

### ot3 follows your Omarchy theme live

Switching themes with `omarchy-theme-set` (or the Omarchy menu) now recolors an open ot3 window at once, with no restart: the sidebar, conversation, composer, popups and the animated sky all follow the new theme.

### Unified, themed tooltips

ot3's tooltips use Omarchy's unified tooltip style: the theme's colors, border and corner radius, centered above what they describe. They honor `~/.config/omarchy/tooltips.json` (square, rounded or theme shape; theme, transparent or custom border), and a change there applies live.

### Light themes look right

- **Sidebar header**: on light themes the header sky is a soft shade of the theme instead of a dark grey band, so the T3 Code logo and buttons read clearly.
- **Stars and shooting stars** are drawn in the theme's dark ink on light themes, so they show against a light sky. Dark themes are unchanged.
