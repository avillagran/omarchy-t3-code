O3 Code prerelease. Native x86_64 package for Omarchy on Arch Linux. Install or update from the O3 branch's installer:

```bash
curl -fsSL https://raw.githubusercontent.com/avillagran/omarchy-t3-code/feat/o3-brand/install.sh | bash
```

## Fixes

- Devices that run **O3 Server** can be paired and shared over OmaBridge. The bundled OmaBridge is now [0.2.5](https://github.com/avillagran/omabridge/releases/tag/v0.2.5), which publishes and pairs the local server O3 Code registered instead of looking only in `~/.t3`. Before, publishing T3 on such a device failed with `omabridge_t3_unavailable`.
