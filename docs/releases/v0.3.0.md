First **O3 Code** prerelease. Native x86_64 package for Omarchy on Arch Linux. Install or update from the O3 branch's installer:

```bash
curl -fsSL https://raw.githubusercontent.com/avillagran/omarchy-t3-code/feat/o3-brand/install.sh | bash
```

## Highlights

### Choose the local server: O3 Server or T3 Code

The installer asks which local server O3 Code drives. **O3 Server** ([o3-server](https://github.com/avillagran/o3-server) v0.1.0, recommended) is a light native server compatible with T3 Code clients: it is installed from a pinned, hash-verified release, runs as the `o3-server.service` user unit on `127.0.0.1:3773` and needs neither the T3 package nor its window. **T3 Code nightly** keeps working as before. `O3_SERVER=o3|t3` chooses without asking; without a terminal a new install uses O3 Server, and existing setups keep their server. The running server can be switched from the sidebar.

### O3 Code

The app is renamed **O3 Code** (`o3`, with `ot3` kept). It adds:

- a project-first sidebar with Classic, Focus and project layouts, groups, pinned threads and search by field, word start and initials;
- a thread board and delta live streams;
- shared drafts with the composer and project stash;
- automatic connection assistants, a host-named local environment and per-host provider sign-in;
- OmaBridge 0.2.4 with every host offered from one invitation and T3 shared automatically between paired devices;
- confirmed remote host maintenance and an opt-in document snapshot broker.

## Fixes

- Sidebar metadata no longer enters layout cycles at narrow widths.
- Cleanup quarantines validated output before deleting it and never crosses mounts or nested checkouts.
- Remote media links play and sidebar menus survive updates.
