Native aarch64 and x86_64 packages for Omarchy on Arch Linux. Install or update with the README one-liner:

```bash
curl -fsSL https://raw.githubusercontent.com/avillagran/omarchy-t3-code/main/install.sh | bash
```

## Highlights

### One-step install on a fresh machine

- The installer now sets up **T3 Code nightly** itself when it is missing (`t3code-nightly-bin`, from Omarchy's repository or the AUR through `yay`/`paru`) and opens it once so T3 creates its profile. The local backend then runs as T3's own service, so it keeps running when no T3 window is open. On a terminal, the installer asks whether to open T3 Code afterwards.
- A failing step is named instead of the installer stopping silently, and `curl | bash` never runs a partially downloaded script.

### Agent memory

**Preferences → General → Agent memory** releases idle agent sessions after five minutes by default, with a global timeout and per-environment or per-provider overrides, including Never. The conversation resumes on the next message.

### Lighter desktop UI

Menus, utility pages, review controls, model-picker contents and video playback load only when used, long discarded histories are reclaimed, and the graphics texture atlas is much smaller. Measurements are in `docs/UI_MEMORY.md`.

## Fixes

- The panel opens under the bar on Omarchy versions whose bar spans the whole screen, instead of at the bottom of the screen.
- After T3's profile is recreated, ot3 issues a new local credential instead of staying unauthorized.
- Updating a checkout pinned to an annotated release tag no longer fails with "Binary and source revisions differ".
- Multiplexed SSH forwards keep their owner, and connection failures show a persistent reason.
- A global animations switch, sidebar selections revealed in the mosaic, and Ctrl+B visibility separated from Super+B focus.
