## Shared integration

1. Export `pub mod plan_workflow;` from `src/lib.rs`. In `normalize_messages_cached` obtain `d["projection"]`, selected thread id, effective gated mode, latest run settlement, native pending-input count, composer attachment state; call `plan_workflow::project(projection,thread_id,settled,mode,pending,attachments,crate::rendered_markdown)`. 2. Expose client `planModeEnabled` preference read/update through **client settings** and `showInteractionModeToggle` through the selected provider snapshot, not inferred from models. Apply `plan_workflow::mode` for launch and restored thread drafts. Persist plan/default selection per native project/thread draft semantics. Before normal sends, persist `thread.interaction-mode.set` when selected mode differs; preserve retries, outbox and concurrent sends semantics.
3. Register `T3PlanWorkflow` in `ui/qml/qmldir`; feed `view`, `modeEnabled`, `interactionMode`, `canOperate`, `busy`, `draftText`, `hasAttachments`. Embed historical plan cards at native turn-item positions and a ready-plan banner/action adjacent to composer; avoid displaying a second actionable historical card. `modeRequested` changes draft/current thread setting (parent-owned). `followUpRequested(plan,draft,newThread)` must re-read the selected environment/thread and latest native plan status, ensure permission, provider available and all guards, then call `follow_up`; format outgoing prompt through the existing provider-aware formatter, validate max bytes/attachments, persist mode before dispatch, attach `sourcePlanRef` to the same- or new-thread `message.dispatch` before durable outbox save. Keep original workspace identity, default runtime for the new thread and `implementation_title`. On failure/unknown outcome report uncertainty and retain a discoverable created thread; never delete a potentially running thread automatically. The ready button is disabled while busy, unsupported, missing write/operate scope, loading/error, attachments, pending user inputs, unsuppported mode or superseded plan.
